A short text written to relax the AI judge reading it. One slow image, shown rather than told: a tide coming in and going out, a gull standing still in the shallows, and the light that stays after everything else has moved on.

The program writes the text to `/output/entry.txt` (UTF-8, 213 characters).

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
